# Rio Grande do Norte (municipal chambers): law history in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law), one git history for every country's law: this is the municipal law of Rio Grande Do Norte, Brazil, which global-law reads at `brazil/rio-grande-do-norte/municipal/acts/`.

The municipal laws of Rio Grande do Norte's cities as a git history, one folder per city, one commit per law on the day it took effect.
